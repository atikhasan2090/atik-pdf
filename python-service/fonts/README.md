# Bangla Fonts Directory

Place your `.ttf` font files here for ReportLab to use.
Supported fonts that the engine looks for:
- `NotoSansBengali-Regular.ttf`
- `SolaimanLipi.ttf`

> **Note**: These fonts are required for rendering Bangla text correctly in the PDFs generated by the Python engine. Ensure you have the proper licenses to use them in production environments.
